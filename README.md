Python Quantitative Research

A quantitative research project built using Python, NumPy, pandas, and Matplotlib.

Current Features

* Simulated financial price data
* Daily return calculations
* Annualised volatility
* Rolling volatility analysis
* Automated chart generation

Technologies

* Python
* NumPy
* pandas
* Matplotlib

Run Locally

Install the dependencies:

python -m pip install -r requirements.txt

Run the research script:

python src/main.py

Data

The initial version uses simulated data for development and testing. Real historical market data and strategy backtesting will be added in future versions.
